# RMR Platform v5.0 Master Product Acceptance Matrix

This matrix converts the approved v4.6 product-design baseline into functional v5.0 acceptance requirements.

## Legend

- **A** — administer/configure
- **C** — create
- **E** — edit/update
- **V** — view
- **RO** — read-only support visibility
- **O** — own/assigned records
- **T** — team-scoped records
- **All** — all records in the client tenant
- **—** — not available

Roles:

- **RMR** — RMR Owner / Global Super Administrator
- **S2** — Step2 Platform Administrator
- **CA** — Client Administrator
- **VP** — VP of Sales
- **SM** — Sales Manager
- **SR** — Sales Representative
- **MKT** — Marketing User
- **EV** — Executive Viewer
- **PUB** — anonymous public user
