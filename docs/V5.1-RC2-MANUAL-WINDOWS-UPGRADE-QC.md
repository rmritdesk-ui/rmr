# v5.1 RC2 Exact Windows Upgrade QC Sequence

Use this sequence on Dave’s current Windows Docker Desktop machine. Do not modify source files.

## Upgrade gate

1. Confirm the existing v5.0 application opens and CAF is still present.
2. Close the v5.0 browser tab; leave Docker Desktop running.
3. Extract RC2 into a new folder. Do not reuse the failed RC1 folder.
4. Double-click `UPGRADE-FROM-V5.0.bat` in the RC2 folder.
5. Paste the full path to the existing v5.0 folder.
6. Confirm the command window remains open and reports readiness progress rather than failing on the first connection error.
7. Confirm the final message says **UPGRADE COMPLETED SUCCESSFULLY**.
8. Open RC2 `data\LAST-UPGRADE-RESULT.json` and confirm `status` is `success`.
9. In Docker Desktop, confirm the RC2 container is running and healthy.
10. Open `http://localhost:8080` and sign in with the existing RMR Owner account.

## Preservation and workflow checks

11. Confirm CAF appears in Portfolio Command Center and the tenant selector.
12. Open CAF Client 360.
13. Confirm CAF onboarding notes and completed stages survived.
14. Confirm CAF Client Pricing and negotiated services survived.
15. Confirm the Client Administrator invitation/access controls are available.
16. Create or resend a CAF Client Administrator invitation and activate it in a private browser session.
17. Confirm the CAF user sees only CAF and cannot access Portfolio, other tenants, Client Pricing administration or Partner Economics.
18. As CAF, create a CRM record; as RMR, confirm it is visible only in read-only support view.
19. Use Back/breadcrumb controls to move between CAF Client 360 and Portfolio without browser Back.
20. Open System Health and confirm the plain-English message and technical checks.

## Evidence

Retain:

- the upgrade command-window screenshot/transcript;
- `data\LAST-UPGRADE-RESULT.json`;
- any file under `data\diagnostics`;
- Docker Desktop container screenshot;
- CAF preservation and client-login screenshots.

## Failure rule

If any upgrade step fails, do not retry immediately and do not patch code. Confirm whether the command says v5.0 was restored. Send `LAST-UPGRADE-RESULT.json` and the diagnostic text file to RMR/ChatGPT.
