# RMR Global v5.4 Tenant Themes — Changelog

## Source

Exact Product Owner-approved v5.3.1 ZIP, SHA-256 `d188a52eab6494cb61bcecd828616d4bc17a1fa30cd5ddd2ff54e28555b5f1bf`, verified before extraction and left unchanged.

## Additions

- Additive `tenant_themes` table keyed by tenant ID.
- Tenant theme read/update/reset API and protected logo upload/read/delete API.
- Validated colors, bounded fonts, safe defaults, computed readable foreground colors, audit events, and tenant-scoped logo storage.
- Tenant branding preview and management UI in RMR Client 360 and Client Administrator Team & Settings.
- Authenticated workspace application of tenant brand identity, colors, typography, and optional logo.
- Distinct Kerry and CAF Product Owner themes; all other tenants retain the RMR default until configured.
- Functional QC expanded to 200 checks, including theme role/tenant isolation and logo handling.
- Restart persistence expanded to 10 checks, including tenant-theme persistence and CAF isolation.
- Isolated Windows/Docker Product Owner environment on port 8085.

## Migration

`005.006.000-tenant-themes` creates only the new tenant-scoped branding table. No existing table is rewritten. Existing tenant, CRM, PIQ, website, onboarding, pricing, Partner Economics, audit, and user data remain untouched.

## Not changed

Public website themes, external websites, CRM architecture, ProspectIQ provider boundaries, campaign email delivery boundaries, onboarding stages, billing, pricing formulas, navigation architecture, and accepted v5.3.1 workflows.
