# RMR Platform v5.1 RC2 Change Log

**Release:** `5.1.0-rc2`  
**Baseline:** `5.1.0-rc1`  
**Scope:** Windows/Docker upgrade reliability only. Application features, tenant workflows, permissions and data models from RC1 are preserved.

## Changed

- Replaced the one-shot Windows PowerShell health request with bounded readiness polling.
- Added separate checks for container state, Docker health, internal API health, host-port API health and exact application version.
- Added retry handling for transient Windows connection resets/refusals.
- Added early detection of stopped, dead or repeatedly restarting containers.
- Reduced Docker health-check interval and expanded startup retries for faster, more reliable readiness evidence.
- Added pre-upgrade validation of the currently running v5.0 installation.
- Changed the migration container invocation to use an explicit Python entrypoint, avoiding unnecessary duplicate application-entrypoint work.
- Added automatic diagnostic collection before rollback.
- Added `COLLECT-DIAGNOSTICS.bat`, `.ps1` and `.sh`.
- Added `data/diagnostics` and `data/LAST-UPGRADE-RESULT.json` conventions.
- Added verification that the automatically restored v5.0 installation becomes healthy.
- Improved plain-English console success/failure/rollback messages.
- Updated install, start, update, restore and rollback health validation to use the RC2 readiness gate on Windows.
- Updated release metadata to `5.1.0-rc2`.

## Preserved unchanged

- v5.1 client-user provisioning and invitation/activation.
- tenant isolation and role-based permissions.
- RMR/Step2 read-only support access to client operational data.
- Client 360, Client Pricing, Partner Economics, CRM, onboarding, forecasting, training, websites, Solutions Center, campaigns and ProspectIQ workflows.
- additive v5.0-to-v5.1 database migration and preservation behavior.
- automatic safety backup and separation of the untouched v5.0 installation.

## Not claimed

RC2 was not executed on Windows Docker Desktop in the build environment. The exact RC2 package must pass Dave’s external Windows upgrade test before Hasan handoff.
