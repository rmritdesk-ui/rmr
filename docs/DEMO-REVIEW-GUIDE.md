# RMR Platform v5.1 Demonstration Review Guide

Install with the `demo` profile. All demonstration data is fictional and must not be used for real client operations.

## RMR Owner / Step2 Administrator

Review Portfolio, Client Success, Client Pricing, Service Catalog, Partner Economics, Client Onboarding, Training, Service Requests, Support Access and System Health.

Create a new client with a unique primary-contact email. Confirm the secure Client Administrator invitation/activation path rather than an administrator-known password.

## Client activation and tenant separation

Use the invitation link to activate the client account, set the client’s password and enter the tenant-specific client portal. Confirm global portfolio/economics functions are absent and another tenant cannot be accessed.

## Client operations

As a Client Administrator:

- create account/contact/opportunity/activity;
- update a forecast;
- use active services and Solutions Center;
- review Website Studio and training;
- request an available solution.

Return to RMR and confirm Client 360 reflects relationship/access state, RMR support views are read-only, notifications deep-link correctly and activation synchronizes Client Pricing/training only after approval.

## Operational resilience

Run health, backup, restore and restart-persistence checks. Use the full sequence in `V5.1-MANUAL-QC-SEQUENCE.md` for release acceptance.
