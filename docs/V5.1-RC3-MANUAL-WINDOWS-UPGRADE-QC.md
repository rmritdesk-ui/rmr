# v5.1 Commercial Candidate Exact Windows Upgrade QC Sequence

Use this sequence on the current Windows Docker Desktop machine. Do not modify v5.0 source files or database records.

## Upgrade gate

1. Confirm the existing v5.0 application opens and CAF is still present.
2. Close browser tabs that could change v5.0 data; leave Docker Desktop running.
3. Extract the RC3 ZIP into a brand-new folder. Do not extract over v5.0, RC1 or RC2.
4. Double-click `UPGRADE-FROM-V5.0.bat` inside the **inner RC3 application folder** if Windows extraction created a wrapper folder.
5. Paste the full path to the **inner v5.0 application folder** containing `.env`, `docker-compose.yml`, `data`, `rmr_platform`, `START` and `STOP`.
6. Confirm preflight does not spend 90 seconds rejecting the healthy v5.0 version alias. It should recognize v5.0 as ready and proceed.
7. Leave the command window open while RC3 creates the safety backup, copies data, builds, migrates and starts.
8. Confirm the final message says **UPGRADE COMPLETED SUCCESSFULLY** and **RMR Platform v5.1 Commercial Candidate is healthy and ready.**
9. Open RC3 `data\LAST-UPGRADE-RESULT.json` and confirm `status` is `success` and `release` is `5.1.0-commercial-cb1`.
10. In Docker Desktop, confirm the RC3 container is running and healthy.
11. Open `http://localhost:8080` and sign in with the existing RMR Owner account.

## Preservation and workflow checks

12. Confirm CAF appears in Portfolio Command Center and the client selector.
13. Open CAF Client 360.
14. Confirm CAF onboarding notes and completed stages survived.
15. Confirm CAF Client Pricing and negotiated services survived.
16. Confirm Client Administrator invitation/access controls are available.
17. Create or resend a CAF Client Administrator invitation and activate it in a private browser session.
18. Confirm the CAF user sees only CAF and cannot access Portfolio, other tenants, Client Pricing administration or Partner Economics.
19. As CAF, create a CRM record; as RMR, confirm it is visible only through authorized read-only support visibility.
20. Use Back/breadcrumb controls to move between CAF Client 360 and Portfolio without browser Back.
21. Open System Health and confirm the plain-English message and technical checks.

## Evidence to retain

Keep the upgrade command-window screenshot/transcript, `data\LAST-UPGRADE-RESULT.json`, any file under `data\diagnostics`, Docker Desktop container screenshot, and CAF preservation/client-login screenshots.

## Failure rule

If RC3 fails, do not immediately retry or patch source. Confirm whether the command reports that v5.0 was restored. Send `LAST-UPGRADE-RESULT.json` and the newest diagnostic text file back to ChatGPT.
