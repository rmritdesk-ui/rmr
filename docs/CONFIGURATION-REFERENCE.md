# RMR Platform v5.1 Configuration Reference

Configuration is supplied through `.env`. The installer creates it from `.env.example` and replaces installer placeholders.

| Variable | Purpose | Pilot default |
|---|---|---|
| `RMR_APP_VERSION` | Image/application version | `5.1.0-commercial-cb1` |
| `RMR_IMAGE_REPOSITORY` | Local/container image repository | `rmr-platform` |
| `RMR_PUBLIC_PORT` | Host port mapped to app | `8080` |
| `RMR_ENVIRONMENT` | development/pilot/production label | `pilot` |
| `RMR_BASE_URL` | Public base URL used in links | `http://localhost:8080` |
| `RMR_COOKIE_SECURE` | Secure session cookie requirement | `false` |
| `RMR_SESSION_HOURS` | Session lifetime | `12` |
| `RMR_MAX_UPLOAD_MB` | Application upload limit | `250` |
| `RMR_PAYMENT_PROVIDER` | Payment integration selector | `mock` |
| `RMR_INSTALL_PROFILE` | `empty` or `demo` | `empty` |
| `RMR_ALLOW_DEMO_CREDENTIALS` | Expose demo accounts | `false` |
| `RMR_AUTO_MIGRATE` | Apply migrations at startup | `true` |
| `RMR_AUTO_SEED` | Seed demo dataset | `false` |
| `RMR_SECRET_KEY` | Session/security secret | generated by installer |
| `RMR_SETUP_TOKEN` | One-time first-run token | generated by installer |
| `RMR_INVITATION_HOURS` | Invitation expiration | `168` |
| `RMR_PASSWORD_RESET_MINUTES` | Reset-link expiration | `30` |
| `RMR_LOCAL_RECOVERY_MODE` | Show/write local recovery links | `true` in pilot |
| `DATABASE_URL` | Database connection | SQLite data volume when omitted |
| `RMR_CONTAINER_UID/GID` | Non-root container identity | `10001` |

## Production-oriented changes

Before network-accessible use:

```text
RMR_ENVIRONMENT=production
RMR_BASE_URL=https://approved-hostname
RMR_COOKIE_SECURE=true
RMR_LOCAL_RECOVERY_MODE=false
```

Configure approved SMTP/provider delivery before disabling local recovery. Never expose `.env`, setup tokens, reset links or live secrets.
